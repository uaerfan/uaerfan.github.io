AHE 603

College and University Teaching Portfolio

My AHE 603 portfolio applies engaged teaching, pedagogical content knowledge, backward design, assessment, active learning, and student engagement to a graduate-level Program Analysis course.

Course Design

A graduate Program Analysis course organized around explicit learning outcomes, instructional alignment, and a progression from foundations to authentic analysis tasks.

Learning Outcomes

Students explain analysis concepts, construct program representations, perform data-flow analysis, implement analyses, evaluate trade-offs, and create a substantial analysis project.

Assessment

Homework, programming assignments, research-paper discussions, a midterm, and a semester project provide multiple forms of evidence of learning.

Active Learning

Lectures are combined with problem solving, peer explanation, short analysis exercises, paper discussion, and applied coding tasks.

Student Engagement

Students connect theory to real software, participate in discussion, make meaningful project choices, and apply program-analysis methods to authentic problems.

Reflection & Improvement

Formative feedback is used to identify misconceptions, adjust pacing, manage cognitive load, and strengthen alignment among goals, methods, and assessments.

Program Analysis focus: static and dynamic analysis, control-flow and data-flow analysis, abstract interpretation, pointer and alias analysis, interprocedural analysis, symbolic execution, program slicing, and security-oriented analysis.
